# 备货与通知验收（2026-11-13）

## 功能

- 付款后的待接单订单要求备货人逐项核对实物与数量；自动刷新保留已勾选项，出餐阶段重新核对。
- 缺货选择餐品并填写说明，暂停备货和配送。商家可补货重派、转派或按原有权限发起全额退款；顾客同步看到缺货处理中。
- 新单、转派、缺货、超时未接单通知进入持久发送队列；配置入口位于电脑后台「接单通知」。备货与移动管理员均有微信绑定和订阅入口。

## 已验证

- Maven 全部 60 项测试通过，包括真实 HTTP 状态码、接单检查、缺货处理、转派、退款权限、通知去重、订阅额度、超时结果及收件账号切换。
- 客户端 7 项 Node 测试通过；H5、管理后台及微信小程序生产构建通过。
- 隔离 MySQL 环境通过 Playwright 完成付款测试单、缺货反馈、电脑后台补货重派、接单、出餐核对、配送及送达全流程。轮询后勾选仍保留。没有在营业数据库制造付款或退款。
- 320、390、430 像素手机宽度检查通过；电脑后台检查订单处理及通知配置。企业微信群地址保存后不回显。
- 最终小程序构建在微信开发者工具中通过勾选拦截、出餐重置、制作中缺货后返回暂停详情，以及两步订阅授权入口检查。此项使用隔离数据与微信授权模拟，不代表真实人员收到消息。
- 代码与发布产物进行敏感信息扫描；源代码未发现已知密钥、PAT、私钥等，也未包含 node_modules、构建目录、环境私密文件。

## 发布

后端与网页使用发布目录 `/opt/ktv/releases/20261113-fulfilment-final-1.0.5`。发布前备份数据库及配置；逐项校验后端 JAR 全部 289 个条目及网页 SHA-256。模拟支付仍关闭，真实微信支付配置保留，后台验证码保持启用。

微信官方 CLI 已上传开发版本 **1.0.5**，包大小 **1533584 字节**。体验版切换需在公众平台完成；发布记录本身不代表已经设置体验版。

电脑后台部署在 `/admin/` 时必须带基础路径构建：

```powershell
$env:VITE_APP_BASE_PATH = '/admin/'
npm run build:prod
```

## 需由实际使用人员完成

实际小程序已添加「订单任务待处理提醒」模板，服务器配置模板映射。接收账号需在 1.0.5 小程序内连接本人微信并授权，或由商家在电脑后台配置企业微信群机器人。一次性订阅每授权一次只可发送一条，用完需要重新授权。

尚未以真实备货人的微信或接单群完成消息送达验收。应在实际人员完成授权/群配置后，以允许的营业订单核对新单、缺货及超时提醒。不能将代码测试通过或渠道受理等同于人员已读。
